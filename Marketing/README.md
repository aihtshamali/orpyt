# Marketing Assets

Use this directory for App Store and public launch assets.

## Folder Layout

- `AppStore/` — screenshots, app preview media, and metadata notes for App Store Connect
- `OnlinePresence/` — social launch graphics, website images, thumbnails, and press assets

## Recommended File Naming

- `appstore-01-menubar.png`
- `appstore-02-timescroller.png`
- `appstore-03-weather-calendar.png`
- `appstore-04-settings.png`
- `social-linkedin-launch.png`
- `social-reddit-preview.png`
- `social-x-thumbnail.png`

Keep exported images in their final delivery format and keep any source files beside them where helpful.
